# JS Quiz App 🎯

A simple and interactive Quiz App built with vanilla JavaScript.

## Features
- Multiple choice questions
- Score tracking
- Right answer shown on wrong selection

## Technologies Used
- HTML
- CSS
- JavaScript (DOM Manipulation, Event Listeners)

## How to Run
1. Clone this repository
2. Open `index.html` in browser
3. Start playing!
